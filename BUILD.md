# Build

`npm test` runs the available smoke tests. `npm run build` creates `dist/Dentiva-Portable-v1.0.0/` as a source preview package. `npm start` serves the shell on port 4173.

A Windows installer, portable self-contained executable, and ZIP cannot be honestly produced in this Linux environment because no .NET SDK, Windows SDK, Wine, or installer toolchain is available. Do not treat the current package as the requested native release.
